이미지 및 로고 처리
==================
- 회사 제공 SVG 2종과 브로슈어 제품 로고를 사용했습니다. SVG 5개 모두 viewBox가 있고 <image>/base64 래스터가 없습니다.
- 회사 로고는 스크롤 전/후와 모든 페이지에서 같은 SVG입니다. 헤더 흰 박스 제거, 푸터 흰 박스 유지.
- 이전 로고 PNG는 로컬 assets/_unused/ipeun-logo.png에 보관했습니다. _unused/는 기존 gitignore에 의해 커밋 제외입니다.
- 새 웹용 미디어 25개 및 기업 증빙 20개를 WebP로 적용했습니다. 크기는 원본 해상도 범위에서 조정했고 제품에 초록색 오버레이를 넣지 않았습니다.
- 모델 이미지 생성 도구를 호출하지 않았습니다. 기존 v15 모델 이미지를 유지하고 화면 구도를 위해 여백만 크롭했습니다. 원본 배경 톤을 이어 사진 경계의 빈 띠를 피했습니다.
- 2배 표시 해상도를 목표로 최적화하되 작은 원본을 억지로 확대하지 않았습니다. 특히 RF 기술 그림(459×306)은 고해상도 원본이 필요합니다. 기존 모델·일부 브로슈어 컷도 원본 픽셀 수가 선명도의 상한입니다.

검증 결과
=========
- 콘텐츠 7페이지 × 320/390/768/1024/1280/1440/1920px = 49개 화면 검증. 768px 이하는 모바일 에뮬레이션.
- 문서 가로 넘침 0, 깨진 이미지 0, 콘솔 오류 0. 모바일 제품 카드·목차의 내부 가로 넘기기는 의도된 동작입니다.
- 히어로 3장을 7개 폭에서 별도로 캡처·배치 확인했습니다.
- Chrome/Safari 실제 탭에서 새 심볼 확인. 헤더/푸터 SVG 표시 확인.
- 데스크톱 메뉴 호버와 Tab 진입/하위항목 이동 확인.
- 모바일 3개 아코디언 열기/닫기, 하나만 열림, 스크롤 뒤 100dvh 전체화면, Escape 포커스 복귀와 데스크톱 크기 변경 시 닫힘 확인.
- Home Care: span, aria-disabled=true, href/tabindex 없음.
- 내부 링크 166개 및 고유 이동 목적지 41개 확인. 누락 앵커 0, 누락 자산 0, 새 이미지 width/height 누락 0.
- product.html 리다이렉트 정상.
- 인증·특허·수상 자료 20개 모두 확대 이미지 로드, Escape 닫기, 트리거 포커스 복귀 확인.
- 슬라이더 6초 자동 전환, 호버·포커스·수동 일시정지, prefers-reduced-motion 자동 전환 중단, 이전/다음·선택 버튼 확인.
- 이미지 없는 비활성 슬라이드는 inert/aria-hidden 처리.
- 라벨 최소 12px, 작은 텍스트 라벨의 일반 배경 대비 4.5:1 이상 확인. 이는 사이트 전체 WCAG 인증을 의미하지 않습니다.
- index.html에서 JavaScript 차단/실패 시 js 클래스 제거 및 숨겨진 콘텐츠가 없음을 확인했습니다.
- 금지 문구 HTML 검색 결과 0: No Pain / Just Results / 리프팅 효과 / 콜라겐 / 6개월 / HIFU. 제품 표기·이전 ceo 이메일·PNG 로고 참조도 확인했습니다.
- node --check script.js, git diff --check 통과.
- favicon PNG 32×32 RGBA, Apple 아이콘 180×180 RGB·흰 모서리 확인.
